# Giribala Balasubramanian — Personal Portfolio

## Run locally

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite (usually http://localhost:5173/).

## Resume
Replace `public/Giribala_Balasubramanian_Resume.pdf` with your actual resume PDF using the same filename. The Download CV button will then work.

The hero visual is `public/karuppu-hero.png`. The red-black Karuppu theme includes a scroll-driven 360° photo/orbit rotation effect.

## Customize
Main content is in `src/main.jsx`.
Design is in `src/styles.css`.
